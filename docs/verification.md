## Dockerビルド環境の補足

このクラウド環境のDocker内部では通常のDNSとプロキシCA設定を引き継がず、最初のビルドは名前解決エラー、その切り分け後は証明書検証エラーで停止しました。ホストで解決済みのプロキシ宛先をビルド用に指定し、環境の既存信頼済みCAバンドルをBuildKit secret `build_ca` として渡すことで成功しました。TLS検証の無効化・チェックサムの変更はしていません。CAバンドルやプロキシの秘密値はリポジトリ・イメージに保存していません。

通常のインターネット接続があるサーバーでは README の `docker compose build` を使います。組織の証明書を使う環境では、その管理者が提供する信頼済みCAバンドルを `docker build --secret id=build_ca,src=/path/to/trusted-ca-bundle.pem -t staff-leave .` のように渡せます。証明書検証を無効化して回避しないでください。
